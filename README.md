#Portfolio Website

#Project Introduction

This project is a personal portfolio website and my first project as a beginner in web development. It introduces who I am and shares a short overview of my background. The site highlights my skills and talents so visitors can see what I am learning and what I can do. It also includes a section about my hobbies and the activities I enjoy outside of coding. I built this website to practice basic web development and to create a simple online place that represents me. The project is still growing as I learn new skills and improve the design. Overall, this portfolio is a starting point for my journey as a web developer and a way to show my progress.
